# A Minimal Reporting Standard for Autonomous AI Agent Incidents

Supplementary data for the report *A Minimal Reporting Standard for
Autonomous AI Agent Incidents*, developed as part of the Apart × CeSIA
AI Incident Response Sprint.

## Data

`data/metr_incident_severity_classification.csv` contains the incident-level
severity classifications used in the retrospective analysis.

The underlying incidents were collected from publicly available incident
reports. The L1-L5 severity labels represent application of the severity
taxonomy proposed in the report.
